ADVENTURECAMP
DESKRIPSI PROGRAM: Program Adventure Camp ini dibuat menggunakan bahasa C untuk membantu proses penyewaan peralatan camping. Program ini bisa menampilkan daftar barang dan harga sewa, menghitung total biaya berdasarkan jumlah barang dan lama penyewaan, serta memberikan diskon otomatis. Selain itu, ada fitur struk pembayaran dan riwayat transaksi untuk mencatat hingga 10 transaksi. Program ini juga menggunakan fungsi, array, percabangan, dan perulangan supaya kode lebih terstruktur dan mudah dipahami.
